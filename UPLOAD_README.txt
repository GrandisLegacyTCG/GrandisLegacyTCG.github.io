Grandis Legacy Website v1.6

FULL REPLACEMENT package for the public GrandisLegacyTCG.github.io repository.

GitHub Desktop workflow:
1. Keep the repository's .git folder.
2. Delete the existing project files.
3. Extract this ZIP directly into the repository root.
4. Commit and push to main.
5. GitHub Pages remains: Deploy from a branch -> main -> / (root).

This package preserves /shared/ and the public /pvp/ baseline from v1.5, while refining homepage spacing, making Discover circular, and expanding Arvon to local Rulebook + Season 1 card knowledge.
